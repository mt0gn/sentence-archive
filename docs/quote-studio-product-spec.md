# 문장보관소 통합 제품 기준표

이 문서는 기능을 대화별로 따로 추가하면서 이전 합의가 빠지는 일을 막기 위한 단일 기준표다. 이후 개편은 신규 요청만 구현하지 않고, 이 기준표 전체에 대한 회귀 검증을 거친다.

## 2026-07-26 잠금 결정

- **핵심 개편:** 중앙 WYSIWYG 캔버스, px 캔버스·사방 여백·조판 상세값, 하단 고정 페이지 탐색, 규칙 직접 수정과 규칙별 글꼴 적용, 2배·3배 고화질 저장을 함께 유지한다.
- **보완 개편:** 기존 다중 화자를 새로 만들지 않고 유지·보완하며, 메신저 하단 입력창 고정, 실제 검은 채움/빈칸 숨김, 프로젝트 삭제, 형광펜 추가·제거 분리, 원고지 자유 px, 마이크로필름 상단 여백·본문 세로 정렬, A4·Letter 문서 레이아웃을 포함한다.
- **회귀 금지:** 삭제한 나눔고딕·나눔명조·마루부리를 재추가하지 않는다. 일반 문단 편집에 메신저 전용 설정을 섞지 않는다. 의미 역할을 골랐다는 이유만으로 임의 스타일을 강제하지 않는다.

## 제품 원칙

- GitHub Pages 같은 정적 호스팅에서 서버비 없이 동작한다.
- 외부 AI, OCR, 플랫폼별 전용 파서에 의존하지 않는다.
- 원문을 보존하고 수정본과 분리하며, 실제 출력 결과가 작업 화면 중앙에 즉시 반영된다.
- PC와 모바일에서 같은 기능을 제공한다.
- HTML은 원문 코드와 태그 제거 결과까지만 확인하며 렌더링하지 않는다.

## 원문·프로젝트

- 직접 붙여넣기와 텍스트·HTML·JSON 파일 불러오기를 지원한다.
- 작업 중인 내용이 있을 때 불러오기 전에 덮어쓰기·새 프로젝트·취소를 고르게 한다.
- 원문과 수정본을 분리해 표시하고 양쪽 패널을 접고 펼칠 수 있다.
- 변경 후 자동 저장하고, 미저장 상태에서 닫을 때 경고한다.
- 여러 프로젝트와 ‘내 디자인 보관함’을 브라우저 안에 저장한다.
- 텍스트 및 프로젝트 JSON으로 내보내고 다시 불러올 수 있다.

## 편집·구문 규칙

- 사용자가 시작·종료 기호와 의미를 직접 지정한다.
- 발견한 구문은 자동 분류하지 않고 미지정 상태로 둔다.
- 규칙별 색상, 굵기, 기울임, 글꼴, 크기, 형광펜, 장식선, 기호 숨김을 제공한다.
- 만든 규칙은 삭제 후 재작성하지 않고 직접 수정할 수 있다.
- 중첩·충돌은 경고하되 사용자가 조정한다.
- 규칙과 별도로 선택 범위 수동 서식을 제공한다.
- 실행 취소·다시 실행과 키보드 단축키를 제공한다.
- HTML 태그 제거, 찾기·일괄 변경, 조사 보정, 실제 모자이크를 제공한다.

## 캔버스·조판

- 중앙에는 텍스트 입력창이 아니라 편집 결과 캔버스를 둔다.
- 캔버스 가로·세로를 px로 직접 입력하고 비율 잠금을 제공한다.
- 위·오른쪽·아래·왼쪽 여백을 px로 따로 조절하고 연동할 수 있다.
- 글자 크기, 굵기, 줄 간격, 자간, 문단 간격, 가로 장평, 정렬, 줄바꿈, 단, 그림자를 제공한다.
- 전체·너비·높이 맞춤과 사용자 확대율을 제공한다.
- 확대하거나 캔버스를 스크롤해도 페이지 탐색은 작업대 하단에 고정한다.
- 작은 글씨는 저장 경고를 제공하며 프리텐다드 12px는 안정 조합으로 안내한다.
- 수동 페이지 구분을 우선하고, 별도 자동 페이지 분할은 문단 경계를 우선한다.

## 디자인

- 단색, 3색 그라데이션, 이미지 배경, 종이 질감을 제공한다.
- 이미지 배경의 맞춤, 위치, 배율, 흐림, 오버레이 색과 투명도를 조절한다.
- 프리텐다드, 나눔명조, G마켓 산스, Mona12, 노토 고딕·명조, 고운 바탕·돋움을 프로젝트 내장 웹글꼴로 제공한다.
- 삭제하기로 한 나눔고딕, 나눔명조, 마루부리는 다시 추가하지 않는다.
- UI는 직선적인 회색 와이어프레임과 고정 파랑 `#6694EA`를 사용하고, 결과물 색상과 분리한다.

## 레이아웃

- 클래식, 말풍선, 카카오톡형, DM형, 원고지, 노트, 마이크로필름, A4·Letter 문서, 책자, 스크랩북을 제공한다.
- 카카오톡형과 DM형은 휴대폰 캡처 규격을 고정한다.
- 원고지는 기본 20×10, 중앙 미니멀 5×3, 정방형 8×6, 전면 20×20, 중앙 세로쓰기 4×10 양식을 시작점으로 제공하되, 최종 가로·세로 px와 칸 수는 자유롭게 조절한다.
- 노트와 마이크로필름은 일반 규격과 배너 규격을 제공한다.
- 이미 구현된 메신저 다중 화자를 유지하고 이름, 방향, 색, 프로필 이미지, 시간, 읽음 상태를 설정한다.
- 말풍선은 내용 길이에 맞게 수축하고 최대 너비만 제한한다.
- 원고지는 실제 칸과 제목·매수·꼬리말 요소를 제공한다. 자유 배치는 빈 캔버스가 아니라 선택한 원고지 양식과 격자를 유지한 채 문단·사진·스티커 위치를 조절하는 모드다.
- 책자는 단면·펼침·표지와 러닝 헤더를 제공한다.
- 스크랩북은 문단·이미지·스티커를 자유 배치하고, 손그림·누끼·고급 자르기는 범위에서 제외한다.

## 내보내기·품질

- PNG, JPEG, WebP와 현재 페이지 복사를 제공한다.
- 2배·3배 저장 배율을 제공하고, 선택한 글꼴을 데이터로 포함한 뒤 렌더링한다.
- 모든 페이지 ZIP과 긴 이미지 저장을 제공한다.
- 저장 전 모자이크 여부와 실제 출력 픽셀을 확인한다.

## 통합 회귀 검증

- 불러오기 경고와 프로젝트 분기가 유지되는가.
- 중앙 캔버스가 작업대 가운데에 읽을 수 있는 크기로 맞춰지는가.
- 확대 후에도 하단 페이지 탐색이 보이는가.
- 실행 취소·다시 실행이 텍스트와 주요 설정을 되돌리는가.
- 구문 규칙을 수정할 수 있고 규칙 글꼴이 실제 대사에 적용되는가.
- 12px 프리텐다드 저장이 선명하고 출력 픽셀이 설정과 일치하는가.
- 고정 레이아웃의 규격과 메신저 다중 화자·시간이 유지되는가.
